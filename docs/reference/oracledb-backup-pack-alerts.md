# Oracle RMAN backup pack alerts

Generated by `scripts/gen-pack-alerts.py` from `packs/oracledb-backup/rules.yml`; do not edit. Each alert is a heading named as the alert, so its anchor is the lowercased name. An alert with two severities has one entry per tier.

## OracleBackupStale

The newest completed RMAN job of a kind (database or archivelog) is older than the tolerated age (obenhub.backup_age.limit, 26 h by default). Check V$RMAN_BACKUP_JOB_DETAILS and the scheduler that runs the backups.

**warning**, for 1m

```text
(
  oracledb.backup.age{oracledb.backup.kind="database"}
    > on() group_left()
  (obenhub.backup_age.limit{oracledb.backup.kind="database"} or on() vector(93600))
)
  or
(
  oracledb.backup.age{oracledb.backup.kind="archivelog"}
    > on() group_left()
  (obenhub.backup_age.limit{oracledb.backup.kind="archivelog"} or on() vector(18000))
)
```

## OracleBackupFailed

The most recent finished RMAN job of a kind failed and no later job of that kind has succeeded. Check V$RMAN_BACKUP_JOB_DETAILS for the status and the RMAN log of that job.

**critical**, for 2m

```text
oracledb.backup.failed == 1
```

## OracleBackupClusterNameMissing

An RMAN backup series carries no obenhub.cluster.name, so OracleBackupMissing cannot join it to the Data Guard role. Fix the resource attribute of the Collector.

**warning**, for 5m

```text
oracledb.backup.age{obenhub.cluster.name=""}
```

## OracleBackupMissing

A database that is primary according to the Data Guard pack has no completed database backup series for 30 minutes. This is expected on a fresh or newly promoted primary until its first backup; otherwise check the backup job on this site.

**warning**, for 30m

```text
max by (oracledb.database.unique_name, service.instance.id, obenhub.cluster.name) (
  last_over_time(oracledb.database.primary[1m])
) == 1
  unless on(obenhub.cluster.name, oracledb.database.unique_name)
oracledb.backup.age{oracledb.backup.kind="database"}
```

## OracleRecoveryAreaFull

More than 85 % of the recovery area is in use after counting reclaimable space as free, for 10 minutes. A full area stops archiving on the primary and redo apply on the standby; check what holds the space (V$RECOVERY_AREA_USAGE) and the retention policy.

**warning**, for 10m

```text
(oracledb.recovery_area.usage - oracledb.recovery_area.reclaimable)
  / oracledb.recovery_area.limit
  > 0.85
```
