# CloudNativePG pack alerts

Generated by `scripts/gen-pack-alerts.py` from `packs/cnpg/rules.yml`; do not edit. Each alert is a heading named as the alert, so its anchor is the lowercased name. An alert with two severities has one entry per tier.

## CNPGPrimaryChanged

A member that is now writable (postgresql.recovery.active 0) was in recovery within the last 3 minutes: a replica was promoted, by switchover or failover; the signal cannot tell them apart. Check the CloudNativePG Cluster status for the current primary and why it changed.

**warning**, no hold time

```text
max by (k8s.namespace.name, obenhub.cluster.name) (
  (last_over_time(postgresql.recovery.active[1m]) == 0)
    and on(service.instance.id, k8s.namespace.name, obenhub.cluster.name)
  (max_over_time(postgresql.recovery.active[3m]) == 1)
)
```

## CNPGClusterNameMissing

The instance's CloudNativePG exporter series carry no obenhub.cluster.name, so the cluster rules would group it under an empty name. Fix the resource attribute of the Collector that scrapes the pod.

**warning**, for 5m

```text
cnpg_collector_fencing_on{obenhub.cluster.name=""}
```

## CNPGInstanceFenced

CloudNativePG reports the instance fenced (cnpg_collector_fencing_on 1) for a minute: the operator stopped PostgreSQL in the pod, which stays Running but not ready. Check the cnpg.io/fencedInstances annotation on the Cluster.

**warning**, for 1m

```text
cnpg_collector_fencing_on == 1
```
