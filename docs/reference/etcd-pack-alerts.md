# etcd pack alerts

Generated by `scripts/gen-pack-alerts.py` from `packs/etcd/rules.yml`; do not edit. Each alert is a heading named as the alert, so its anchor is the lowercased name. An alert with two severities has one entry per tier.

## Thresholds

Each row is a limit a rule compares against: the default is in the rule, and a lab overrides it by recording the series (ADR 0006, lab parameters). A tiered alert reads one series with a `severity` label per tier. The selector is the label matcher of the series the rule reads.

| Alert | Series | Selector | Default | Unit | Fires when the value is |
| --- | --- | --- | --- | --- | --- |
| EtcdHighLeaderChanges | `obenhub.etcd.leader_changes.limit` |  | 3 | `{change}` | at or above the limit |
| EtcdHighFsyncDurations | `obenhub.etcd.fsync_duration.limit` |  | 0.5 | `s` | above the limit |
| EtcdHighCommitDurations | `obenhub.etcd.commit_duration.limit` |  | 0.25 | `s` | above the limit |

## EtcdMemberAbsent

An expected etcd member has had no successful scrape for 2 minutes while the Collector that scrapes it is alive. Run etcdctl endpoint status against all members to see which one does not answer, then check the etcd process on it.

**warning**, for 1m

```text
obenhub.expected_scrape{service.name="etcd"}
  unless on(obenhub.cluster.name, service.instance.id)
(max_over_time(up{service.name="etcd"}[2m]) == 1)
  and on(obenhub.collector)
label_replace(present_over_time(otelcol_process_uptime[1m]), "obenhub.collector", "$1", "service.instance.id", "(.+)")
```

## EtcdInsufficientMembers

Fewer etcd members report than a majority of the cluster's inventory (2 of 3), so the cluster has lost quorum or cannot be seen. Check which members are absent (EtcdMemberAbsent) and bring them back.

**critical**, for 1m

```text
WITH (
  inv = obenhub.expected_scrape{service.name="etcd"},
  members = count by (obenhub.cluster.name) (inv)
)
(
  count by (obenhub.cluster.name) (
      inv
        and on(obenhub.cluster.name, service.instance.id) (max_over_time(up{service.name="etcd"}[2m]) == 1)
    or
      inv
        unless on(obenhub.collector) label_replace(present_over_time(otelcol_process_uptime[1m]), "obenhub.collector", "$1", "service.instance.id", "(.+)")
  )
    or
  members * 0
)
  < on(obenhub.cluster.name)
((members + 1) / 2)
```

## EtcdClusterNameMissing

An etcd member's series carry no obenhub.cluster.name, so the member alerts count it toward no cluster. Fix the resource attribute of the Collector scrape.

**warning**, for 5m

```text
up{service.name="etcd", obenhub.cluster.name=""}
```

## EtcdNoLeader

A reporting etcd member has had no leader (etcd_server_has_leader 0) for a minute; a normal election takes about a second. Run etcdctl endpoint status to see which member is leader, and check the network between the members.

**critical**, for 1m

```text
etcd_server_has_leader == 0
```

## EtcdHighLeaderChanges

Three or more leader changes of one etcd cluster within 5 minutes (3 unless the lab sets obenhub.etcd.leader_changes.limit; increase of etcd_server_leader_changes_seen_total). Run etcdctl endpoint status for the current leader, and look at the members for restarts, slow disks (EtcdHighFsyncDurations) or network trouble between them.

**warning**, for 1m

```text
max by (obenhub.cluster.name) (increase(etcd_server_leader_changes_seen_total[5m]))
  >= on() group_left()
(obenhub.etcd.leader_changes.limit or on() vector(3))
```

## EtcdHighFsyncDurations

The 99th percentile of the WAL fsync duration of a member is over the limit (0.5 s unless the lab inventory sets obenhub.etcd.fsync_duration.limit) for 10 minutes. Check the disk under the etcd data directory for contention.

**warning**, for 10m

```text
histogram_quantile(0.99, rate(etcd_disk_wal_fsync_duration_seconds_bucket[5m]))
  > on() group_left()
(obenhub.etcd.fsync_duration.limit or on() vector(0.5))
```

## EtcdHighCommitDurations

The 99th percentile of the backend commit duration of a member is over the limit (0.25 s unless the lab inventory sets obenhub.etcd.commit_duration.limit) for 10 minutes. Check the disk under the etcd data directory for contention.

**warning**, for 10m

```text
histogram_quantile(0.99, rate(etcd_disk_backend_commit_duration_seconds_bucket[5m]))
  > on() group_left()
(obenhub.etcd.commit_duration.limit or on() vector(0.25))
```
