# pgBackRest pack alerts

Generated by `scripts/gen-pack-alerts.py` from `packs/pgbackrest/rules.yml`; do not edit. Each alert is a heading named as the alert, so its anchor is the lowercased name. An alert with two severities has one entry per tier.

## PgBackRestClusterNameMissing

The pgBackRest exporter scrape carries no obenhub.cluster.name. Fix the resource attribute of the Collector scrape.

**warning**, for 5m

```text
up{service.name="pgbackrest", obenhub.cluster.name=""}
```

## PgBackRestBackupStale

The last completed backup of a stanza is older than the tolerated age (obenhub.backup_age.limit, 26 h by default), for a minute. Run pgbackrest info for the stanza and check the job that takes the backups.

**warning**, for 1m

```text
pgbackrest_backup_since_last_completion_seconds{backup_type="incr"}
  > on() group_left()
(obenhub.backup_age.limit or vector(93600))
```

## PgBackRestBackupChecksumError

The last backup of a stanza found pages whose checksum does not match: damage in the data files, which PostgreSQL itself reports only when it reads the page. The backup still completes, so the stale alert stays silent; check pgbackrest info and the pgBackRest log of that backup (invalid page checksum found).

**critical**, no hold time

```text
pgbackrest_backup_last_error_status{backup_type="incr"} > 0
```

## PgBackRestStanzaError

pgbackrest_stanza_status is not 0 for 2 minutes: the stanza is missing or has no valid backup (the first backup of a new lab takes about a minute). Run pgbackrest info and pgbackrest check for the stanza.

**critical**, for 2m

```text
pgbackrest_stanza_status != 0
```

## PgBackRestExporterDown

The exporter cannot read the repository (pgbackrest_exporter_status 0) or the Collector cannot scrape the exporter (up 0) for 2 minutes. While it fires the backup age is frozen or absent; check the exporter's log.

**warning**, for 2m

```text
up{service.name="pgbackrest"} == 0
  or
pgbackrest_exporter_status == 0
```
