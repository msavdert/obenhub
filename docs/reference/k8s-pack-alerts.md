## KubernetesNodeNotReady

The Ready condition of a node is not True for a minute (False, Unknown or not listed). Read the Ready condition with kubectl get node and the Node events (VictoriaLogs, object.regarding.kind Node).

**critical**, for 1m

label_replace(k8s.node.condition_ready != 1, "service.instance.id", "$1", "k8s.node.name", "(.+)")
