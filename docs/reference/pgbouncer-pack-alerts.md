# PgBouncer pack alerts

Generated by `scripts/gen-pack-alerts.py` from `packs/pgbouncer/rules.yml`; do not edit. Each alert is a heading named as the alert, so its anchor is the lowercased name. An alert with two severities has one entry per tier.

## Thresholds

Each row is a limit a rule compares against: the default is in the rule, and a lab overrides it by recording the series (ADR 0006, lab parameters). A tiered alert reads one series with a `severity` label per tier. The selector is the label matcher of the series the rule reads.

| Alert | Series | Selector | Default | Unit | Fires when the value is |
| --- | --- | --- | --- | --- | --- |
| PgbouncerClientsWaiting | `obenhub.pgbouncer.oldest_wait_age.limit` |  | 10 | `s` | above the limit |
| PgbouncerPoolSaturated | `obenhub.pgbouncer.pool_usage_ratio.limit` |  | 0.9 | `1` | at or above the limit |
| PgbouncerClientSaturation | `obenhub.pgbouncer.client_connection_ratio.limit` | `severity="warning"` | 0.85 | `1` | above the limit |
| PgbouncerClientSaturation | `obenhub.pgbouncer.client_connection_ratio.limit` | `severity="critical"` | 0.95 | `1` | at or above the limit |
| PgbouncerWaitTime | `obenhub.pgbouncer.avg_wait_time.limit` |  | 0.1 | `s` | above the limit |
| PgbouncerWaitTime | `obenhub.pgbouncer.oldest_wait_age.limit` |  | 10 | `s` | at or above the limit |

## PgbouncerTargetAbsent

An expected PgBouncer target has sent no heartbeat (the SHOW LISTS row databases) for 2 minutes while its Collector is alive. Check that PgBouncer runs and that the stats user can reach the console.

**critical**, for 1m

```text
obenhub.expected_target{service.name="pgbouncer"}
  unless on(obenhub.cluster.name, service.instance.id)
present_over_time(pgbouncer.list.item.count{pgbouncer.list.name="databases"}[2m])
  and on(obenhub.collector)
label_replace(present_over_time(otelcol_process_uptime[1m]), "obenhub.collector", "$1", "service.instance.id", "(.+)")
```

## PgbouncerClusterNameMissing

A PgBouncer target carries no obenhub.cluster.name, so the saturation and wait rules pair it with nothing. Fix the resource attribute of the Collector.

**warning**, for 5m

```text
pgbouncer.list.item.count{pgbouncer.list.name="databases", obenhub.cluster.name=""}
```

## PgbouncerCollectionIntervalTooLong

PgBouncer is collected less often than every 15 s (average spacing above 20 s over 5 minutes), while the rules size their windows for 15 s, so they go quiet or flap. Set the collection interval back to 15 s.

**warning**, for 10m

```text
max by (obenhub.cluster.name, service.instance.id) (scrape_interval(pgbouncer.list.item.count{pgbouncer.list.name="databases"}[5m])) > 20
```

## PgbouncerClientsWaiting

A client has waited over the limit (10 s unless the lab sets obenhub.pgbouncer.oldest_wait_age.limit) for a server connection for a minute, so the pool is at pool_size with clients queued. Run SHOW POOLS on the PgBouncer console for cl_waiting and maxwait of the database named in the alert.

**warning**, for 1m

```text
(
  pgbouncer.pool.oldest_wait_age{pgbouncer.database.name!="pgbouncer"}
    + pgbouncer.pool.oldest_wait_subsecond_age{pgbouncer.database.name!="pgbouncer"}
      > on() group_left()
    (obenhub.pgbouncer.oldest_wait_age.limit or on() vector(10))
)
  unless on(obenhub.cluster.name, service.instance.id, pgbouncer.database.name)
(pgbouncer.database.paused == 1 or pgbouncer.database.disabled == 1)
  and on(obenhub.cluster.name, service.instance.id)
present_over_time(pgbouncer.list.item.count{pgbouncer.list.name="databases"}[2m])
```

## PgbouncerPoolSaturated

The pool of a database has had 90 % or more (unless the lab sets obenhub.pgbouncer.pool_usage_ratio.limit) of its pool_size linked to clients on average over 5 minutes; no client waits yet. Run SHOW POOLS for sv_active and compare it with pool_size in SHOW DATABASES.

**warning**, no hold time

```text
WITH (
  r = pgbouncer.pool.active_server.count{pgbouncer.database.name!="pgbouncer"}
    / on(obenhub.cluster.name, service.instance.id, k8s.pod.uid, pgbouncer.database.name) group_left()
  (pgbouncer.database.server_connection.limit > 0),
  x = avg_over_time(r[5m:15s]),
  n = count_over_time(r[5m:15s])
)
((x >= on() group_left() (obenhub.pgbouncer.pool_usage_ratio.limit or on() vector(0.9)))
  and (n >= 20))
  unless on(obenhub.cluster.name, service.instance.id, pgbouncer.database.name)
(pgbouncer.database.paused == 1 or pgbouncer.database.disabled == 1)
  and on(obenhub.cluster.name, service.instance.id)
present_over_time(pgbouncer.list.item.count{pgbouncer.list.name="databases"}[2m])
```

## PgbouncerClientSaturation

Client connections are above 85 % of max_client_conn (critical at 95 %, when further clients are refused), unless the lab sets obenhub.pgbouncer.client_connection_ratio.limit per severity. Run SHOW LISTS for used_clients and SHOW CONFIG for max_client_conn.

**warning**, no hold time

```text
WITH (
  r = pgbouncer.list.item.count{pgbouncer.list.name="used_clients"}
    / on(obenhub.cluster.name, service.instance.id, k8s.pod.uid)
  pgbouncer.client_connection.limit,
  x = min_over_time(r[75s:15s]),
  n = count_over_time(r[75s:15s])
)
(
  (
    (x > on() group_left() (obenhub.pgbouncer.client_connection_ratio.limit{severity="warning"} or on() vector(0.85)))
      unless
    (x >= on() group_left() (obenhub.pgbouncer.client_connection_ratio.limit{severity="critical"} or on() vector(0.95)))
  )
    and (n >= 5)
)
  and on(obenhub.cluster.name, service.instance.id)
present_over_time(pgbouncer.list.item.count{pgbouncer.list.name="databases"}[2m])
```

**critical**, no hold time

```text
WITH (
  r = pgbouncer.list.item.count{pgbouncer.list.name="used_clients"}
    / on(obenhub.cluster.name, service.instance.id, k8s.pod.uid)
  pgbouncer.client_connection.limit,
  x = min_over_time(r[75s:15s]),
  n = count_over_time(r[75s:15s])
)
((x >= on() group_left() (obenhub.pgbouncer.client_connection_ratio.limit{severity="critical"} or on() vector(0.95)))
  and (n >= 5))
  and on(obenhub.cluster.name, service.instance.id)
present_over_time(pgbouncer.list.item.count{pgbouncer.list.name="databases"}[2m])
```

## PgbouncerWaitTime

Clients wait more than 0.1 seconds on average (unless the lab sets obenhub.pgbouncer.avg_wait_time.limit) for a server assignment over 5 minutes (many short waits that stay under the oldest wait limit of PgbouncerClientsWaiting). Run SHOW STATS for the database and check the pool size against the load.

**warning**, for 2m

```text
(
  rate(pgbouncer.stats.wait_time{pgbouncer.database.name!="pgbouncer"}[5m])
    / (rate(pgbouncer.stats.server_assignment{pgbouncer.database.name!="pgbouncer"}[5m]) > 0)
      > on() group_left()
    (obenhub.pgbouncer.avg_wait_time.limit or on() vector(0.1))
)
  unless on(obenhub.cluster.name, service.instance.id, pgbouncer.database.name)
max by(obenhub.cluster.name, service.instance.id, pgbouncer.database.name) (
  max_over_time(
    (
      min_over_time(pgbouncer.pool.oldest_wait_age{pgbouncer.database.name!="pgbouncer"}[75s])
        >= on() group_left()
      (obenhub.pgbouncer.oldest_wait_age.limit or on() vector(10))
    )[6m:15s]
  )
)
  unless on(obenhub.cluster.name, service.instance.id, pgbouncer.database.name)
(pgbouncer.database.paused == 1 or pgbouncer.database.disabled == 1)
  and on(obenhub.cluster.name, service.instance.id)
present_over_time(pgbouncer.list.item.count{pgbouncer.list.name="databases"}[2m])
```
