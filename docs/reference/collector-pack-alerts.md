# Collector pack alerts

Generated by `scripts/gen-pack-alerts.py` from `packs/collector/rules.yml`; do not edit. Each alert is a heading named as the alert, so its anchor is the lowercased name. An alert with two severities has one entry per tier.

## Watchdog

Fires always (expr vector(1)) so that a working alert pipeline has a standing alert. If Alertmanager shows it missing, rules, vmalert or the notification path stopped working.

**none**, no hold time

```text
vector(1)
```

## CollectorAbsent

An expected Collector (obenhub.expected_collector) has sent no self-metrics (otelcol_process_uptime) for 2 minutes, so nothing it collects is seen. Check whether the Collector process or container is running, and its upstream gateway if it sends through one.

**critical**, for 1m

```text
(
  obenhub.expected_collector
    unless on(service.instance.id)
  present_over_time(otelcol_process_uptime[2m])
)
  unless on(obenhub.upstream)
label_replace(
  obenhub.expected_collector
    unless on(service.instance.id)
  present_over_time(otelcol_process_uptime[1m]),
  "obenhub.upstream", "$1", "service.instance.id", "(.+)")
```

## CollectorUnknown

An inventory entry names a Collector (obenhub.collector) that is not in obenhub.expected_collector, or has no such label, which would switch off that target's absent alerts silently. Correct the label in the lab inventory.

**warning**, for 1m

```text
(obenhub.expected_target or obenhub.expected_scrape)
  unless on(obenhub.collector)
label_replace(obenhub.expected_collector, "obenhub.collector", "$1", "service.instance.id", "(.+)")
```
